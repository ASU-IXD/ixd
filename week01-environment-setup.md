# Week 1: Environment Setup

## Objectives

By the end of this week, you should be able to:

- Set up the NVIDIA Omniverse Kit development environment.
- Create your first Omniverse Kit application.
- Launch and verify that your application runs successfully.
- Become familiar with the available Omniverse application templates.

---

## Prerequisites

Before starting, ensure that your computer meets the system requirements and that all required software is installed.

Follow the official NVIDIA guide for the required software installation and environment configuration:

- [Prerequisites and Environment Setup](https://github.com/NVIDIA-Omniverse/kit-app-template#prerequisites-and-environment-setup)

> **Important:** Complete every step in the setup guide before proceeding to the next section.

---

## Create Your First Omniverse Application

After completing the environment setup, follow the official **Quick Start** guide to create and launch your first Omniverse application.

- [Quick Start Guide](https://github.com/NVIDIA-Omniverse/kit-app-template#quick-start)

By the end of this section, you should have:

- Cloned the Kit App Template repository.
- Created a new application using one of the available templates.
- Built the project successfully.
- Launched the application without errors.

---

## Omniverse Application Templates

The Kit App Template includes several application templates. Read the descriptions below to understand their intended use cases.

| Template | Description |
|----------|-------------|
| **Kit Service** | A minimal headless Omniverse Kit service for backend applications that do not require a graphical interface. |
| **Kit Base Editor** | A lightweight graphical application for loading, editing, and rendering OpenUSD content. |
| **USD Composer** | An application template for authoring complex OpenUSD scenes such as configurators and interactive environments. |
| **USD Explorer** | An application designed for exploring and collaborating on large OpenUSD scenes. |
| **USD Viewer** | A viewport-only application intended for viewing and streaming OpenUSD content. |
