# NVIDIA Learning Resources

This page contains recommended NVIDIA training courses that complement the material covered in this course. These self-paced courses provide hands-on experience with OpenUSD and Omniverse Kit development and are highly recommended for all students.

It is recommended that students complete the courses in the following order:

1. **[Fundamentals of Working With OpenUSD](https://github.com/ASU-IXD/ixd/new/main#fundamentals-of-working-with-openusd)**
2. **[Extend Omniverse Kit Applications for Building Digital Twins](https://github.com/ASU-IXD/ixd/new/main#extend-omniverse-kit-applications-for-building-digital-twins)**

# Fundamentals of Working With OpenUSD

**Course Link:**  
[Here](https://learn.nvidia.com/courses/course?course_id=course-v1:DLI+S-OV-15+V1&unit=block-v1:DLI+S-OV-15+V1+type@vertical+block@d1876bc99b9141f6813eb796f564b231)

## Description

This course introduces the fundamentals of **OpenUSD (Universal Scene Description)**, the open and extensible framework for creating, composing, and exchanging 3D scenes. Through guided lessons and hands-on exercises, you will learn how OpenUSD organizes scene data, enables non-destructive workflows, and supports scalable collaboration across complex 3D projects. This course provides the foundation for developing applications and digital twins using NVIDIA Omniverse.

## Course Modules

- Introduction
- Setting Up Your Environment
- Navigation Basics
- Module 1: Building an OpenUSD Component
- Module 2: Utilizing Variants
- Module 3: Aggregating the Scene
- Conclusion

# Extend Omniverse Kit Applications for Building Digital Twins

**Course Link:**  
[Here](https://learn.nvidia.com/courses/course?course_id=course-v1:DLI+S-OV-13+V1&unit=block-v1:DLI+S-OV-13+V1+type@vertical+block@d1fe256beea34694a7e9740f765cc671)

## Description

This course builds upon the OpenUSD fundamentals by introducing **NVIDIA Omniverse Kit** application development. You will learn how to develop interactive digital twin applications, work with Omniverse Kit extensions, build and manipulate digital twin scenes, add interactive functionality, and integrate physics simulations. The course emphasizes practical application through hands-on exercises using the Omniverse development environment.

## Course Modules

- Introduction
- Setting Up Your Environment
- Module 1: Preparing for a Digital Twin
- Module 2: Building a Digital Twin Scene
- Module 3: Exploring Interactive Features for a Digital Twin
- Module 4: Adding Physics to a Digital Twin
- Conclusion
